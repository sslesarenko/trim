# Trim

Telegram Mini App: колода карточек услуг. Тап по фото открывает онлайн-запись, кнопка под карточкой ведёт на сайт. Свайп влево или вправо показывает следующую услугу.

Сейчас в колоде заглушки. Реальные тексты, фото и ссылки подставляются в одном файле.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из терминала в браузере. Так удобно проверить свайп, кнопки и ссылки до публикации.

## Как подменить заглушки

Измените список в `src/data/services.ts`. Картинки положите в `public/placeholders/` и укажите путь в поле `image`.

- `bookingUrl` — онлайн-запись, открывается тапом по фото
- `siteUrl` — кнопка «На сайт»

Картинки из `public/placeholders/` подставляйте через `import.meta.env.BASE_URL`, чтобы они открывались и локально, и на GitHub Pages. Внешний адрес можно указать целиком.

## GitHub Pages

Push в `main` собирает статику и публикует её на [https://sslesarenko.github.io/trim/](https://sslesarenko.github.io/trim/). Отдельный бэкенд не нужен.

В настройках репозитория источник Pages должен быть GitHub Actions.

## Подключение к боту

Когда бот понадобится, в [@BotFather](https://t.me/BotFather) укажите адрес Pages как Menu Button или Main App. Токен бота в репозиторий класть не нужно: мини-приложение его не использует.
